# AI Dungeon Master

A roguelike RPG where every quest, NPC dialogue, and dungeon layout is dynamically generated by AI locally in real-time. Built with React, Phaser.js, Express, and Ollama.

## Setup Instructions

### 1. Requirements
Ensure you have the following installed on your system:
- Node.js (v18+)
- Ollama (for local LLM inference)

### 2. LLM Setup (Ollama)
The game requires the `phi3` model running locally.
Run the following command in your terminal:
\`\`\`bash
ollama run phi3
\`\`\`

### 3. Install Dependencies
You need to install dependencies for both the client and the server.

**Server Setup:**
\`\`\`bash
cd server
npm install
\`\`\`

**Client Setup:**
\`\`\`bash
cd client
npm install
\`\`\`

*(Optional: Claude API Key)*
You requested instructions on how to get a Claude API Key:
1. Go to console.anthropic.com.
2. Sign up or log in.
3. Navigate to "API Keys" in your settings.
4. Click "Create Key", copy it, and save it securely.
*(Note: This project is strictly configured to run completely offline via Ollama, so the Anthropic API key is not actively utilized in the source code.)*

## How to Run

1. **Start the Backend Server:**
   Open a new terminal.
   \`\`\`bash
   cd server
   npm start
   \`\`\`
   *Server runs on http://localhost:5000*

2. **Start the Frontend Client:**
   Open a new terminal.
   \`\`\`bash
   cd client
   npm start
   \`\`\`
   *Client runs on http://localhost:3000*

## How to Play

- **Movement:** Use the standard `W, A, S, D` keys or `Arrow Keys` to move around the grid tile by tile.
- **Combat:** Walk into enemies to attack them (Bump-to-attack). Combat resolution is automatic and turn-based based on your Attack/Defense stats.
- **NPCs:** Walk up to an NPC and click them (or bump them) to open the dialogue pane. The fallback UI provides the dialogue overlay where you can chat dynamically.
- **HUD & UI:** The HUD tracks your HP, level, and active quests. You can open the inventory (bottom right) to see your items and use consumables.
- **Quests:** NPCs will dynamically assign you kill quests or item retrieval tasks based on the LLM's generated response!

## Known Limitations and Extensions

- **Limitations:**
  - Standard React-Phaser integration without an established bundle bundler like Vite might require CRA setup overrides, but `react-scripts` covers it here.
  - The Q-Table for Enemy AI acts on simplified state spaces. With complex procedural generated maps, enemies might get stuck behind walls without sophisticated multi-state caching.
  - The LLM inference speed depends entirely on your local hardware. A slower GPU will mean longer "Thinking..." spinners during dialogue.
- **Extensions:**
  - Add real pixel art sprites mapping to the generated assets.
  - Extend the Q-table to track party formations or pack mentalities among enemies.
  - Add multiplayer capabilities by keeping the state synced across the Node.js server using WebSockets.
